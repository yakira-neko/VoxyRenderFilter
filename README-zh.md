# VoxyRenderFilter

在游戏内地图上展示 voxy LOD 缓存覆盖情况，支持按区域渲染过滤、按区域删除 LOD 缓存、地图瓦片缓存与视距/背景透明度调整。

## 功能

### 缓存地图
- 从磁盘 voxy LOD 缓存（全部层级 lvl0–lvl4）生成真实地形地图，远离玩家也能查看；瓦片由小型工作线程池并行生成（2–4 条，按 CPU 核数伸缩）
- **地图瓦片缓存**：每个区域文件（TLN 列，512×512 方块）落盘为 PNG + 哈希边车文件；打开地图"先渲染后验证"——缓存先显示，随后一次性校验哈希失配并后台重生成
- 缓存目录：
  - 单人：`<存档目录>/vrf_mapcache/<维度>/`
  - 多人：`<游戏目录>/vrf_mapcache/<服务器IP>/<世界标识>/<维度>/`（世界标识 = 种子，Velocity 群组服各子服自动分开）
- **IP 映射**：config 中可配置 `"ip1": ["ip2", "ip3"]`，多线路服务器共享同一份缓存（增删改查均经过映射）
- 覆盖层：淡色 = 磁盘已缓存区域，绿色 = 当前渲染环内且有数据的列，橙色 = 被过滤屏蔽的区域；绿色按 voxy 圆形渲染环裁剪，缩小视距后无残留
- 半透明玩家箭头（预览其他维度时不显示；地狱↔主世界互看时按 8:1 换算坐标）
- 高缩放时在选区内绘制区块网格
- 已渲染的列全部保留（不做 LRU 淘汰），扫描/生成不会导致已渲染区域消失

### 扫描与同步
- **扫描模式**（持久化到 config）：自动 = 后台持续异步同步玩家周围（原版视距）的缓存变化并预生成缺失缓存；手动 = 只有点击"重新扫描"才扫描（异步线程进行）
- 手动模式的"重新扫描"只处理区域粒度的选区（区块粒度选区忽略）；新的重新扫描会终止旧的待处理任务
- **维度循环按钮**（`维度:<dimensionId>`）：在已有缓存的维度间轮询；预览其他维度只加载缓存（不验证、不渲染玩家箭头），过滤操作禁用（反选与删除缓存除外）
- 覆盖层仅在打开地图 / 维度切回玩家所在维度时加载（事件驱动，不主动轮询）

### 区域选区
- 左键拖拽框选；右键拖拽剪除；**Ctrl** 切换多选；按住 **Shift** 强制正方形选区
- 低缩放时选区对齐区域文件（32×32 区块），高缩放时对齐 lvl0 section（2×2 区块）
- 多次选择自动合并为互不重叠的选区
- **框选开关**（按钮或 **G**）：关闭后左键直接拖动平移地图，已有选区保留；平移步距为原值的 1/16
- 右键选区弹出操作菜单；右键空白处清除选区
- 滚轮缩放（以光标为中心）；**WASD** / 方向键平移；**R** 重新扫描；**H** 以玩家居中；**C** 清除选区；**回车** 屏蔽；**Del** 删除
- 地图文字区实时显示选区坐标与尺寸（方块/区块/section/区域）

### 渲染过滤
- 屏蔽选中区域渲染、仅渲染选中区域、反选、取消屏蔽；立即生效，无需禁用/重新启用 voxy
- 整列被屏蔽的列从渲染环中移除；部分屏蔽的 lvl0 section（2×2 区块）渲染为空洞
- 反选范围限制在 voxy 圆形渲染视距内
- HUD 左上角实时显示过滤状态（模式、坐标、拦截次数）
- 内置 voxy 节点管理移除竞态的崩溃防护

### 缓存删除
- 删除选区内所有层级的 LOD 缓存（lvl0–lvl4）：粗 LOD 覆盖的区域包含选区，一并删除否则数据会残留
- 渲染节点立即刷新，并从当前磁盘状态重新构建
- 注意：voxy 没有"部分重建 LOD"的公开 API——删除任意细粒度数据会连带删除覆盖它的粗 LOD section（覆盖整个区域文件），该区域需等待世界重新摄入后才恢复
- 误删且已加载的相邻区块会从活世界中重新导入（ingest）

### 地图设置
- **视距输入框**：与 voxy 配置滑块同值（10..1024，2×2 区块为单位），回车应用并持久化到 voxy 配置，与 voxy 实时同步
- **背景透明度输入框**：0-255，持久化
- 右上角按钮栏：清除过滤 / 删除缓存 / 清除选区 / 重新扫描 / 居中 / 覆盖层开关 / 选择开关 / 扫描模式 / 维度切换

### 本地化
- 附带 voxy 与 Sodium 的中文语言文件（运行时覆盖其英文界面）

### 命令
- `/voxyrenderfilter purge <x1> <z1> <x2> <z2>` — 删除方块坐标矩形内的 LOD 缓存
- `/voxyrenderfilter filter rect <x1> <z1> <x2> <z2>` — 设置渲染过滤矩形
- `/voxyrenderfilter filter clear` — 清除过滤
- `/voxyrenderfilter filter status` — 查看当前过滤状态

### 配置（`config/voxyrenderfilter.json`）
- `scanMode` — `"AUTO"` / `"MANUAL"` 扫描模式
- `backgroundAlpha` — 地图背景透明度 0-255
- `ipMappings` — IP 映射表（多线路服务器共享缓存）

## 使用方法

1. 在**控制 → VoxyRenderFilter** 中绑定按键（默认未绑定），或使用上述命令
2. 打开地图，拖拽框选区域
3. 右键选区，选择**屏蔽该区域渲染 / 仅渲染选中区域 / 反选 / 删除缓存 / 清除选区**
4. 按 **Del** 删除选区缓存，按 **回车** 屏蔽选区渲染
