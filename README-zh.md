# VoxyRenderFilter

在游戏内地图上展示 voxy LOD 缓存覆盖情况，支持按区域渲染过滤与按区域删除 LOD 缓存。

## 功能

### 缓存地图
- 从磁盘 voxy LOD 缓存（全部层级 lvl0–lvl4）生成真实地形地图，远离玩家也能看到
- 覆盖层：淡色 = 磁盘已缓存区域，绿色 = 当前渲染且数据可用的列，橙色 = 被过滤屏蔽的区域
- 半透明玩家箭头显示当前所在位置与朝向
- 高缩放时在选区内绘制区块网格
- 右上角按钮栏：清除过滤 / 删除缓存 / 清除选区 / 重新扫描 / 居中 / 覆盖层开关
- 覆盖层开关可隐藏淡色/绿色/橙色覆盖层，直接查看原始地形
- 自动检测磁盘新缓存列（约每 2 秒），无需手动刷新

### 区域选区
- 左键拖拽框选；右键拖拽从已有选区中剪除；**Ctrl** 切换多选；按住 **Shift** 强制正方形选区
- 低缩放时选区对齐区域文件（32×32 区块），高缩放时对齐 lvl0 section（2×2 区块）
- 右键选区弹出操作菜单；右键空白处清除选区
- 滚轮缩放（以光标为中心）；**WASD** / 方向键平移；**R** 重新扫描；**H** 以玩家居中；**C** 清除选区
- 地图文字区实时显示选区坐标与尺寸（方块/区块/section/区域）

### 渲染过滤
- 支持屏蔽选中区域渲染、仅渲染选中区域、反选、取消屏蔽
- 立即生效，无需禁用/重新启用 voxy
- 整列被屏蔽的列会从渲染环中移除；部分屏蔽的 section 渲染为空洞
- 反选范围限制在 voxy 渲染视距内
- 过滤生效时 HUD 左上角显示过滤状态（模式、坐标、拦截次数）

### 缓存删除
- 删除选区内所有层级的 LOD 缓存（lvl0–lvl4）：粗 LOD 覆盖的区域包含选区，一并删除否则数据会残留
- 立即刷新渲染节点，并从当前磁盘状态重新构建
- 误删且已加载的相邻区块会从活世界中重新导入（ingest）

### 命令
- `/voxyrenderfilter purge <x1> <z1> <x2> <z2>` — 删除方块坐标矩形内的 LOD 缓存
- `/voxyrenderfilter filter rect <x1> <z1> <x2> <z2>` — 设置渲染过滤矩形
- `/voxyrenderfilter filter clear` — 清除过滤
- `/voxyrenderfilter filter status` — 查看当前过滤状态

| 26.1      | Fabric | 25+  |

## 使用方法

1. 在**控制 → VoxyRenderFilter** 中绑定按键（默认未绑定），或使用上述命令
2. 打开地图，拖拽框选区域
3. 右键选区，选择**屏蔽该区域渲染 / 仅渲染选中区域 / 反选 / 删除缓存 / 清除选区**
4. 按 **Del** 删除选区缓存，按 **回车** 屏蔽选区渲染
